# Almeida Móveis Planejados

Site institucional da Almeida Móveis Planejados, construído com React + Vite + Tailwind CSS.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion (animações)

## Rodando localmente

```bash
npm install
npm run dev
```

## Estrutura

- `src/Intro.jsx` — tela de abertura animada
- `src/Navbar.jsx` — navbar estilo "dynamic island"
- `src/AccordionGallery.jsx` — galeria de ambientes em accordion
- `src/Testimonials.jsx` — carrossel de depoimentos
- `src/ProjectChat.jsx` — chat estilo iPhone para descrever o projeto
- `src/QuoteModal.jsx` — modal flutuante de solicitação de orçamento (WhatsApp)
